# 拍完好剪｜拍摄与剪辑助手

[打开网页 Demo（无需登录）](https://toxictilltheend.github.io/pai-wan-hao-jian/) · [备用入口](https://haicha-yijing-demo.frillypitch1.chatgpt.site/)

拍摄前列出不能漏拍的画面。剪辑时对照创作目标，检查哪一段缺素材，优先找已经拍过的画面，再决定是否补拍或换一种讲法。

## 试用咖啡制作案例

1. 在时间线上选中「倒入牛奶」，问右侧的小镜「这一段留多长？」。
2. 打开原视频，确认多留几秒能否看清动作，再把预览的区间加进草稿。
3. 问「我已经离店，不能补拍，素材不够怎么剪？」，从未用素材中找到咖啡流进杯中的片段。
4. 查看修改前后，或打开拍摄清单检查下次要拍什么。

网页上的小镜使用案例素材说明和草稿状态给出建议。用户导入的本地视频可以在浏览器播放和标注。自动识别自己拍的视频需要运行本地 AI。网页可下载剪辑方案和拍摄清单，成片可在网页内预览。

## 在自己的电脑上使用 AI

安装 Node.js 20 或更新版本并启动 Ollama。在仓库根目录执行下面的命令，随后在浏览器打开 `http://127.0.0.1:8765/`。Windows 也可以双击 `启动本地AI.cmd`。

```sh
ollama pull qwen3:4b
ollama pull gemma4:latest
node local-ai.cjs
```

Gemma 4 描述视频里的抽样画面，Qwen3 根据画面描述和目标安排镜头，并帮小镜理解问题。选择「我的素材」后可导入视频，先查看原视频时间点，再决定是否采用建议。模型在本机运行，视频和草稿保存在当前浏览器。自动分析每次最多处理 3 段导入视频，每段最多抽取 3 帧，适合检查短片段。
